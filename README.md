# Preparación del Entorno de Desarrollo

Esta guía detalla los requisitos, la instalación de herramientas y la configuración inicial necesaria para poner en marcha el proyecto de desarrollo móvil.

## 1. Herramientas Necesarias
Para trabajar con este proyecto, asegúrate de tener instaladas las siguientes herramientas base:
* **Node.js (LTS)**: Entorno de ejecución para JavaScript (incluye `npm`).
* **Git**: Sistema de control de versiones.
* **Visual Studio Code**: Editor de código recomendado.
* **Expo Go**: Aplicación móvil disponible en Play Store / App Store para probar la app en un dispositivo físico.

### Extensiones recomendadas para VS Code:
* ES7+ React/Redux/React-Native snippets
* Prettier - Code formatter
* ESLint
